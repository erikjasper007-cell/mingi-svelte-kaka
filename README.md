# mingi-svelte-kaka

## Run locally

Install dependencies and start the development server:

```sh
npm install
npm run dev
```

Open the local URL printed by Vite to preview the app. The development server
reloads the page as you edit `app.svelte` and `app.css`.

To create a production build, run `npm run build`. To preview that build locally,
run `npm run preview`.
